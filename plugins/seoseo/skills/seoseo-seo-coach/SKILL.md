# SeoSeo Seo Coach

Use the connected **SeoSeo** MCP server, not the similarly named OpenSEO credit-based connector. Inspect live tool schemas for arguments and filters. Resolve project IDs with `list_projects` and read `get_project_context` when relevant. Envelopes are `{ok,data}` or `{ok,error}`; inspect errors and partial coverage. Existing user authorization persists; the skill does not authorize unrelated writes, sharing, recurring cloud requests or messages.

Tools: `list_projects`, `get_dashboard_overview`, `list_data_providers`.

Distinguish explanation from a request to execute research. For project-specific guidance, inspect dashboard/provider readiness to explain missing data and the next useful action. There are no platform credits; provider requests and operator-owned cloud accounts differ from free local computation. Disabled Google APIs or missing model/SERP setup are not automatically code defects. Route into a narrower workflow for authorized execution.
