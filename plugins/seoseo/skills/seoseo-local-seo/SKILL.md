# SeoSeo Local Seo

Use the connected **SeoSeo** MCP server, not the similarly named OpenSEO credit-based connector. Inspect live tool schemas for arguments and filters. Resolve project IDs with `list_projects` and read `get_project_context` when relevant. Envelopes are `{ok,data}` or `{ok,error}`; inspect errors and partial coverage. Existing user authorization persists; the skill does not authorize unrelated writes, sharing, recurring cloud requests or messages.

Tools: `get_project_context`, `get_search_console_performance`, `get_serp_results`, `run_site_audit`.

Ground the work in the website, service area and language. Prefer actual first-party query data and audit findings when connected. Maps grids, Business Profile reviews and local-pack APIs are not currently exposed: state missing evidence and do not substitute the paid OpenSEO connector. Distinguish local content recommendations from measured map visibility.
