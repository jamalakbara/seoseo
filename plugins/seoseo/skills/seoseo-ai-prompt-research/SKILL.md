# SeoSeo Ai Prompt Research

Use the connected **SeoSeo** MCP server, not the similarly named OpenSEO credit-based connector. Inspect live tool schemas for arguments and filters. Resolve project IDs with `list_projects` and read `get_project_context` when relevant. Envelopes are `{ok,data}` or `{ok,error}`; inspect errors and partial coverage. Existing user authorization persists; the skill does not authorize unrelated writes, sharing, recurring cloud requests or messages.

Tools: `get_project_context`, `research_ai_visibility_prompts`, `list_ai_visibility_models`.

Generate candidate questions from the user topic/positioning, then review them for duplication, relevance and unwanted brand insertion. Label model drafts and the model used. Do not create trackers, enable recurring schedules or collect answers unless also requested. Generated questions do not establish consumer-chat search frequency.
