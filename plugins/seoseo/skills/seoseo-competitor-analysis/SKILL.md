# SeoSeo Competitor Analysis

Use the connected **SeoSeo** MCP server, not the similarly named OpenSEO credit-based connector. Inspect live tool schemas for arguments and filters. Resolve project IDs with `list_projects` and read `get_project_context` when relevant. Envelopes are `{ok,data}` or `{ok,error}`; inspect errors and partial coverage. Existing user authorization persists; the skill does not authorize unrelated writes, sharing, recurring cloud requests or messages.

Tools: `get_domain_overview`, `get_domain_authority`, `get_domain_age`.

Hold market and project keyword scope fixed, and paginate observed keywords as needed. Inspect coverage, dates and exact/metasearch flags. Traffic is a heuristic for the observed sample only when eligible imported monthly search volume exists; null is not zero. Registry registration age is not website age or proof of continuous ownership. Recommend concrete pages/topics supported by the evidence.
