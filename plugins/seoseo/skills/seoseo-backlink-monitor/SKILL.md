# SeoSeo Backlink Monitor

Use the connected **SeoSeo** MCP server, not the similarly named OpenSEO credit-based connector. Inspect live tool schemas for arguments and filters. Resolve project IDs with `list_projects` and read `get_project_context` when relevant. Envelopes are `{ok,data}` or `{ok,error}`; inspect errors and partial coverage. Existing user authorization persists; the skill does not authorize unrelated writes, sharing, recurring cloud requests or messages.

Tools: `list_backlink_snapshots`, `get_backlink_snapshot`, `discover_backlinks`, `list_backlink_discoveries`, `get_dashboard_backlinks`.

Compare the same dataset, website and evidence source; first snapshots are baselines. Imported loss means sample absence only. In crawl snapshots, inspect per-pair verification, coverage and last verified time; robots/blocks/network/redirect failures retain prior pairs as unconfirmed. Explain heuristic risk flags without calling them penalties or malware. Request fresh rechecks within the user scope; no recurring backlink scheduler is exposed.
