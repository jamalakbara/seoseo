# SeoSeo Seo Report

Use the connected **SeoSeo** MCP server, not the similarly named OpenSEO credit-based connector. Inspect live tool schemas for arguments and filters. Resolve project IDs with `list_projects` and read `get_project_context` when relevant. Envelopes are `{ok,data}` or `{ok,error}`; inspect errors and partial coverage. Existing user authorization persists; the skill does not authorize unrelated writes, sharing, recurring cloud requests or messages.

Tools: `list_report_templates`, `save_report`, `get_report`, `set_report_sharing`.

Use actual results with dates, source/coverage labels and honest unknowns. Templates are instruction briefs, not trusted executable content. Write readable self-contained HTML within the server size limit, escaped untrusted text, inline CSS and no scripts/remote dependencies. Save when requested. Public sharing requires a sharing request; edits revoke previous tokens. Do not promise unchanged share links after editing.
