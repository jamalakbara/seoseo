AI trackers are immutable, website-scoped configurations with up to 10 prompts, 10 literal brand terms and 3 approved models. Creating a tracker makes no provider request. Explicit admin runs atomically enqueue frozen input snapshots and gateway fingerprints; model blocks/network/truncation stop collection, preserve partial answers and leave failed/unattempted cells unknown. Internal failures retry and skip saved successes; no exactly-once external-call promise across crashes. Rates use successful answer cells only, and unverified model-reported URL strings are never fetched. One operator-configured HTTP(S) gateway including local Ollama supports free use; project inputs cannot change endpoints or arbitrary model IDs. Scheduling, prompt generation, grounded engines and SoV/trends remain later M5 work.
