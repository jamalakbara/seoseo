M8 exposes eleven anonymous tools with global shared Postgres request budgets (120 analysis and 10 network checks per minute). HTML/JSON/XML inputs are parsed, never executed or persisted. Public redirects use guarded DNS and exact-origin robots-aware manual hops. Log summaries retain status and declared bot-family counts only, not even URL paths, with a 20-summary project bound. SERP volatility uses complete distinct top-ten URL pairs for saved current-market keywords, same exact engine within 30 days; the own rank movement index stays separate. Merchant Web Bot Auth credentials are encrypted, never returned, and only attached to the exact HTTPS host before expiry; renderer/browser requests never receive them. CPC is explicit operator Google Ads BYOK, with nulls when unconfigured and account currency verification before measured results. Telemetry is off by default, manually sent only after instance-admin opt-in, with version-only payload and no built-in receiver. MCP Apps use a static CSP-constrained resource and textContent rendering with structured/JSON fallback. Locale scaffolding is en/id navigation and public tools, not a claim that all legacy screens are translated.
